A make.fun entry for **One Line, One Chill**: a single sentence of horror, under 200 characters, written to `/output/entry.txt`. One line, one breath — a child's daily drawings quietly reveal that a stranger has been standing behind the narrator in every single one, a dread that only grows the longer you sit with it.

## Run

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The program refuses to write anything outside 1–200 characters, anything only whitespace, or anything containing a newline.
